⛏️ Data Warehouse Analítico -- Minería Chile

A local dbt + DuckDB warehouse for Chilean copper mining. The real layer is built from Cochilco's 2000-2025 statistical yearbook; a second, simulated layer unifies flotation, truck maintenance and safety at shift grain, because no public shift-level data exists.
